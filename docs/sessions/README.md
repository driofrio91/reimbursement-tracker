# Session Notes

## Objetivo

Esta carpeta guarda una bitacora corta de cada sesion de trabajo para poder retomar el proyecto sin perder el hilo.

## Regla de uso

- una sesion de trabajo relevante debe dejar un archivo nuevo en esta carpeta
- registrar solo hechos verificados, no brainstorming largo
- si una decision cambia el rumbo del proyecto, debe reflejarse tambien en la documentacion principal

## Contenido minimo de cada sesion

- objetivo de la sesion
- cambios realizados
- decisiones tomadas
- validaciones ejecutadas
- estado resultante
- siguiente paso recomendado

## Orden de lectura para retomar

1. `docs/START-HERE.md`
2. `docs/09-current-status.md`
3. el archivo mas reciente de esta carpeta
